# 최근 운영 화면 반응형 시각 검증

## 변경 이유

최근 추가한 계정·보안·감사·대량 목록 화면이 `SDTPL_ADM` 기반 전체 레이아웃과 모바일 작업 환경에서 실제로 사용할 수 있는지 같은 기준으로 확인할 필요가 있었습니다. 기존 화면 검토 문서는 폐기한 기획용 preview를 가리키고 있어 현재 제품 기준으로 갱신해야 했습니다.

## 변경 내용

- `apps/web/e2e/recent-pages-visual-qa.cjs`로 관리자 11개, 창고 3개, 거래처 2개 경로를 데스크톱·모바일에서 검사합니다.
- 임시 서버 세션을 DB에 생성하고 `finally`에서 제거해 사용자 비밀번호나 MFA 값을 검증 파일에 넣지 않습니다.
- 기대 제목, Geist Sans, 문서 가로 넘침, console error, 실패한 동일 출처 요청을 검사합니다.
- 32개 캡처와 JSON receipt를 남기고 실제 제품 화면 검토 문서와 포트폴리오 데모 진행 순서를 갱신했습니다.
- 저장소 진입점에 제출용 `README.md`를 추가하고 오래된 프로젝트 개요 상태를 실제 검증 결과에 맞게 갱신했습니다.
- 공개 저장소 준비 과정에서 로그·테마 원본·민감 계정 캡처를 Git 제외 대상으로 지정하고 `.env.example`을 추가했으며 변경 이력의 개인 이메일을 익명화했습니다.
- `npm.cmd run repo:verify-public`으로 필수 제외 경로와 공개 후보 텍스트의 개인 관리자 이메일·구체적인 PostgreSQL credential URL을 검사합니다.

## 검증 결과

- `npm.cmd run ui:verify-recent`: 30/30 통과
- 1440×900 및 390×844에서 문서 가로 넘침 0건
- console error 0건, 실패한 동일 출처 요청 0건
- 계정 관리 데스크톱, 감사 로그 모바일, 재고 정정 데스크톱, 출고 작업 모바일, 배송 관리 데스크톱·모바일 캡처 직접 확인

## 범위

이 검사는 화면 조회와 반응형 배치를 확인하는 시각 회귀 스모크입니다. 상태 변경 업무는 기존 PostgreSQL 통합 테스트와 Playwright 업무 E2E로 검증합니다.
