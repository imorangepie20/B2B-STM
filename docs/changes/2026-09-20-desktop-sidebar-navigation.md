# PC 왼쪽 사이드바 내비게이션

작성일: 2026-09-20.

## 변경 이유와 근본 원인

사용자는 PC에서도 모바일과 같은 왼쪽 메뉴 구조를 사용하도록 요청했습니다. 기존 역할별 사이드바 컴포넌트는 데스크톱 표시 기능을 이미 제공했지만, 관리자·거래처·창고 레이아웃이 이를 `md:hidden`으로 감싸 PC에서 숨기고 상단 가로 메뉴를 별도로 표시했습니다. 같은 메뉴가 화면 크기에 따라 서로 다른 위치와 탐색 방식으로 제공되는 것이 원인이었습니다.

## 변경 내용

- 관리자·거래처·창고 레이아웃에서 같은 역할별 사이드바를 모든 화면 크기에 렌더링합니다.
- PC에서는 왼쪽에 펼쳐진 사이드바를 기본 표시하고 트리거·레일로 아이콘 폭까지 접을 수 있습니다.
- 모바일에서는 기존 Sheet 기반 왼쪽 드로어와 메뉴 선택 시 자동 닫힘을 유지합니다.
- 상단의 PC 전용 가로 메뉴와 중복 브랜드 영역을 제거하고, 사이드바 트리거·현재 위치·사용자 정보·로그아웃만 유지합니다.
- 주문·재고·출고·정산 API와 업무 데이터는 변경하지 않았습니다.

## 검증 결과

- `npm.cmd run ui:verify-navigation`: 관리자·거래처·창고 PC 사이드바 표시, 가로 메뉴 제거, 접기 동작, 모바일 드로어 열기·메뉴 이동 후 닫힘을 실제 Chromium에서 확인했습니다.
- `npm.cmd run build:web`: Next.js production build와 TypeScript 검사를 통과했습니다.
- `npm.cmd run test:foundation`: 79/79 통과했습니다.
- 1440×900 PC와 390×844 모바일 관리자 화면을 캡처해 사이드바 고정 배치와 드로어 오버레이를 육안 확인했습니다.
