# 공개 README와 포트폴리오 제출 자료 정리

## 변경 이유

기존 README는 초기 구현 상태와 과거 화면 검증 수치를 포함하고 있어 최신 통계 화면과 운영 검증 범위를 정확히 보여주지 못했습니다. 포트폴리오 평가자가 구현 범위, 기술 판단, 실행 증거, 미실행 항목을 짧은 순서로 확인할 수 있도록 제출 자료를 다시 정리했습니다.

## 변경 내용

- 루트 `README.md`를 실제 업무 흐름, 역할별 화면, 기술 구성, 실행 방법, 검증 결과 순서로 재작성했습니다.
- 최신 관리자 대시보드와 거래처 주문 이력, 창고 출고 작업을 대표 화면으로 선별했습니다.
- `docs/portfolio/README.md`에 제출 자료의 용도와 대표 화면 설명을 정리했습니다.
- 위시켓 설명에 Recharts 기반 역할별 통계와 PostgreSQL 전체 범위 집계 방식을 추가했습니다.
- 데모 진행 순서와 운영 인수표를 최신 26/26 반응형 검증 결과로 갱신했습니다.
- 로컬 스모크와 미실행 목표 규모 성능 시험을 구분해 과장된 성능 주장을 제거했습니다.

## 검증 결과

- README와 포트폴리오 문서의 로컬 Markdown 링크 경로 검사 통과
- `npm.cmd run repo:verify-public`: 제외 규칙 7개, 공개 후보 377개 경로 검사 통과
- 개인 관리자 이메일과 `.env.local`의 민감 값이 공개 후보 파일에 포함되지 않음을 확인
