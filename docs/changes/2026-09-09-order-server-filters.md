# 주문 전체 데이터 서버 필터

## 변경 이유

검색과 상태 필터가 현재 페이지 50건에만 적용되어 다음 페이지의 주문을 찾지 못하고 표시 건수도 전체 결과와 달랐습니다.

## 변경 내용

- 거래처 주문 내역, 관리자 주문 관리, 관리자 주문 이력 API에 `query`, `status`, `from`, `to` 조건을 추가했습니다.
- 주문번호, 거래처, 창고, SKU, 상품명을 DB에서 검색하고 상태·접수일 범위를 전체 주문에 적용합니다.
- 필터가 count와 목록 쿼리에 동일하게 적용되어 페이지 수와 전체 건수가 일치합니다.
- 검색어는 100자, 날짜는 실제 `YYYY-MM-DD`, 상태는 화면별 허용값만 받습니다.
- 세 화면은 검색 입력을 300ms 지연 적용하고 조건 변경 시 1페이지로 이동합니다.

## 검증

- 필터 입력 검증과 실제 HTTP 검색·상태 조회를 포함한 관련 테스트 19건 통과
- foundation 62건, API·웹 production build 통과
