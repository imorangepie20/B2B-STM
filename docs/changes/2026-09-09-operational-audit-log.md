# 운영 감사 로그

## 변경 이유

주요 변경 이력이 각 업무 화면과 테이블에 흩어져 운영자가 작업자·대상·사유를 한 번에 추적하기 어려웠습니다.

## 변경 내용

- `/admin/audit-events`에서 재고 정정, 주문 취소, 반품 검수, 정산 마감, 계정 상태 변경, MFA 초기화를 시간순으로 조회합니다.
- 작업 유형, 작업자·대상·사유 검색, 기간과 서버 페이지 처리를 제공합니다.
- system 또는 operations 역할의 MFA 확인 세션만 접근할 수 있습니다.

## 검증

- 역할·MFA 접근 통제, 유형·검색 필터와 계정 상태 근거 조회 통합 테스트를 추가했습니다.
- foundation, API·웹 build 결과는 현재 개발 인계에 기록합니다.
