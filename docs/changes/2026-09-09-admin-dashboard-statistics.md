# 관리자 대시보드 기간 통계 개편

## 변경 이유

기존 관리자 첫 화면은 처리 대기 건수와 기준정보 위주여서 주문이 실제 출고·매출·정산으로 이어지는 흐름을 판단하기 어려웠습니다. 사용자가 지정한 `http://localhost:2455/dashboard`를 인증 세션으로 확인하고 `design-extract`로 구조·글자·간격·접근성을 측정해, STM 테마 안에서 같은 정보 밀도와 통계 위계를 적용했습니다.

## 변경 내용

- `GET /api/admin/dashboard?days=7|30|90`에 기간 검증과 실제 PostgreSQL 집계를 추가했습니다.
- 기간별 주문·출고·출고 매출·반품 차감·순매출과 주문 상태, 출고 수량 이행률을 반환합니다.
- 현재 재고 구성과 확정 정산서의 청구·수금·미수금, 기존 처리 대기·미배분 입금 필드를 함께 반환합니다.
- 관리자 화면에 조회 기간, 새로고침, 핵심 지표 6개, 주문 분포·재고 구성·정산 수금 분석 카드를 배치했습니다.
- `SDTPL_ADM`과 동일한 `recharts@3.8.0`과 shadcn `ChartContainer`를 설치했습니다.
- 주문 분포와 재고 구성은 `PieChart`, 수금률은 `RadialBarChart`로 구현하고 툴팁·접근성 레이어·빈 데이터 상태를 연결했습니다.
- 설치 후 dependency 감사에서 기존 `next@16.2.7` 취약점이 확인되어 패치 버전 `next@16.3.4`로 갱신했습니다.
- 기존 빠른 입고와 창고별 재고 표는 같은 화면 아래에 유지했습니다.

## 디자인 적용 기준

- 기존 `SDTPL_ADM` 기반 밝은 STM 색상과 Geist Sans를 유지했습니다.
- 분석 대상 화면에서 확인한 24px 제목, 12~14px 본문, 10px 카드 모서리, 16px 안쪽 여백과 조밀한 다단 카드 구성을 반영했습니다.
- 데스크톱에서는 핵심 지표를 최대 5열로 표시하고 작은 화면에서는 1~3열로 재배치합니다.
