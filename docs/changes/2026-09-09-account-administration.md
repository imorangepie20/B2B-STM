# 관리자 계정 운영 화면

## 변경 이유

초대·재초대·비밀번호 재설정 API는 있었지만 관리자가 계정 상태를 조회하거나 화면에서 처리할 수 없었습니다. 발급 토큰을 사용자가 입력할 공개 화면과 계정 회수 이력도 필요했습니다.

## 변경 내용

- `/admin/accounts`에서 내부·거래처 계정을 초대하고 역할과 소속을 지정합니다.
- 계정 목록에서 초대 대기, 비밀번호 설정, 활성 상태를 확인하고 재초대·비밀번호 재설정 토큰을 발급합니다.
- `/account-setup`에서 사용자가 일회성 토큰으로 최초 또는 재설정 비밀번호를 설정합니다.
- 계정 비활성화 시 세션과 미사용 토큰을 폐기하고, 활성·비활성 변경 사유를 `account_status_changes`에 기록합니다.
- 관리자는 자기 계정을 비활성화할 수 없습니다.
- 이메일 전달 전까지 토큰은 관리자 화면에서 한 번만 표시하고 복사해 전달합니다.

## 검증

- 개발·테스트 DB에 migration `0025_account_status_changes.sql` 적용
- 계정 생명주기 통합 테스트 6건 통과
- foundation 60건 통과
- API·웹 production build 통과
