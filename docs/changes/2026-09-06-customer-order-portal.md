# 거래처 주문 포털

거래처 역할로 로그인한 사용자는 인증이 끝난 뒤 `/portal/orders`로 이동합니다. 이 화면은 활성 창고별 주문 가능 상품과 현재 가용수량을 보여 주며, 입력한 수량만 `POST /api/orders`로 접수합니다.

상품의 가격 계약은 아직 구현하지 않았으므로 가격·금액은 표시하거나 저장하지 않습니다. 가용수량은 주문 시점의 참고 정보이고, 주문 접수는 재고를 예약하지 않습니다. 운영 담당자가 `/admin/orders`에서 확정할 때만 실제 가용수량 범위에서 예약됩니다.

`GET /api/orders/catalog`은 거래처 역할만 접근할 수 있으며 활성 창고와 재고가 있는 활성 상품을 반환합니다. `scripts/tests/order-reservation.test.mjs`는 이 접근 경계와 반환된 가용수량을 주문·예약 흐름과 함께 검증합니다.
