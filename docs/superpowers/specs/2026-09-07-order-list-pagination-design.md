# 주문 목록 서버 페이지 처리 설계

작성일: 2026-09-07

## 문제

거래처 주문 내역, 관리자 처리 목록, 관리자 완료 이력 API가 조건에 맞는 모든 주문과 주문행 JSON을 한 번에 반환합니다. 목표 규모 데이터에서는 DB 계산량, 메모리 사용량, 전송량이 주문 수에 비례해 증가하므로 운영 성능 시험과 실제 사용을 막습니다.

## 계약

- `page`와 `pageSize`를 query parameter로 받습니다.
- 기본값은 1페이지, 50건이며 최대 100건입니다.
- 응답은 `items`, `page`, `pageSize`, `total`, `totalPages`를 제공합니다.
- 순서는 기존 업무 우선순위와 최신순 규칙을 유지합니다.
- 잘못된 값과 한쪽 parameter만 전달한 요청은 `400`으로 거부합니다.
- 화면은 서버에서 받은 한 페이지만 검색·상태 필터에 사용하고 이전·다음 버튼으로 이동합니다.

## 성능 원칙

먼저 대상 주문 ID를 정렬·제한한 뒤 선택된 주문에 대해서만 주문행, 출고, 취소 정보를 조립합니다. 전체 건수 조회는 별도 단순 count로 처리합니다. 따라서 상세 JSON 조립량은 전체 주문량이 아니라 `pageSize`에 의해 제한됩니다.
