# 운영 인수 스모크 구현 계획

상태: 로컬 스모크 구현·검증 완료. 목표 규모 30분 본 시험을 대신하지 않습니다.

1. percentile, 응답 요약, 기준 판정 함수를 테스트 우선으로 구현한다.
2. 데모 계정에 임시 세션을 발급하고 역할별 API 허용·거부 행렬을 검증한다.
3. 30개 동시 작업자가 대표 읽기 API를 호출하고 endpoint별 성능을 집계한다.
4. 실패 시에도 임시 세션을 제거하고 사람이 확인할 수 있는 JSON 결과를 출력한다.
5. 프로젝트 명령, 운영 기준 문서, 현재 개발 상태와 변경 이력을 갱신한다.
6. 단위 테스트, 전체 foundation, DB 무결성, 실제 API 스모크를 실행한다.
