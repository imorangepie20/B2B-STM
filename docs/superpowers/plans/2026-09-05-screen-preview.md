# 대표 화면 검토용 구현 계획

상태: 완료된 초기 검토 계획. 이후 실제 제품 화면은 `apps/web`에 다시 구현했으며 최신 화면 기준은 [화면 구성 문서](../../architecture/screen-and-navigation-design.md)입니다.

목표: 승인된 화면 설계에 따라 관리자 주문 상세·거래처 주문·창고 출고를 테마 사본에 구현합니다.
범위: 실제 API·DB·인증 없이 명시적 예시 데이터와 화면 내 상호작용만 제공합니다.
설계: `docs/architecture/screen-and-navigation-design.md`.
기술: 사본의 Next.js·React·shadcn 컴포넌트와 CSS. 제품 스택 확정과는 별개입니다.

- [x] `/b2b-preview` 공통 레이아웃·한국어 글꼴·역할 전환과 예시 표시.
- [x] 관리자 주문 수량·상태·확인 처리, 거래처 주문 수량·조건·접수 확인, 창고 검수·출고 확인.
- [x] Playwright로 3개 경로·모바일 가로 넘침·입력·확인 동작 검증 및 캡처.
- [x] 변경 파일 lint·TypeScript 검사와 원본 보존 확인, 문서·인계 갱신.

원본 `SDTPL_ADM`은 수정하지 않습니다. 화면 간 권한 전환은 검토 편의 기능이며 제품 인증 기능이 아닙니다.
단일 샘플 주문의 서로 다른 업무 시점을 보여주며 실제 상태를 공유·저장하지 않습니다.
