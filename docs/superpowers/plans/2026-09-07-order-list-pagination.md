# 주문 목록 서버 페이지 처리 계획

상태: 구현·검증 완료. 주문뿐 아니라 창고·재고·반품 주요 목록까지 서버 페이지 처리를 확장했습니다.

1. 페이지 입력과 응답 metadata 함수를 단위 테스트로 고정한다.
2. 거래처 주문, 관리자 처리 목록, 관리자 이력 서비스 쿼리에 limit·offset과 count를 연결한다.
3. controller가 페이지 query를 검증하고 동일한 응답 계약을 제공하게 한다.
4. 세 주문 화면에 페이지 상태와 이전·다음 이동을 연결한다.
5. API·웹 build, foundation, 브라우저 업무 흐름, 운영 스모크를 재검증한다.
