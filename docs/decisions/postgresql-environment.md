# PostgreSQL 환경 결정

2026-09-05. 상태: 사용자 확정.

## 결정

Next.js 웹·NestJS 업무 API·PostgreSQL 구성과 기술 구조 제안을 승인했습니다.
PostgreSQL은 이미 Docker에서 실행 중인 인스턴스를 재사용하고 B2B 전용 데이터베이스를 추가합니다.
새 PostgreSQL 인스턴스를 기본 구성으로 만들지 않습니다.

- 부동산 DB와 B2B DB를 분리합니다.
- B2B 전용 접속 계정과 최소 권한을 사용합니다.
- 테스트 전용 DB를 별도로 두며 운영·개발 업무 데이터에 테스트를 실행하지 않습니다.
- 마이그레이션·백업·복원 대상을 프로젝트별로 명시합니다.
- 실제 DB 생성은 전체 기획 확정 후 개발 환경 구성 단계에서 수행합니다.

## 적용 전 확인

기존 컨테이너 이름·PostgreSQL 버전·포트·볼륨·접속 방식과 자원 여유를 읽기 전용으로 확인합니다.
DB·역할 이름의 충돌 여부를 확인하고 신규 대상만 생성합니다. 기존 DB·역할·볼륨은 수정하거나 초기화하지 않습니다.
접속 비밀값은 문서·Git·명령 출력에 기록하지 않습니다.

같은 인스턴스를 사용하므로 DB를 나눠도 CPU·메모리·디스크·서버 장애는 공유합니다.
부하 테스트는 기존 서비스에 영향을 주지 않는 일정·환경을 정한 후 수행합니다.
승인된 RPO 15분·RTO 4시간은 목표이며 현재 Docker 환경이 충족하는지 아직 검증하지 않았습니다.
시점 복구가 필요한 경우 인스턴스 전체 WAL과 DB별 논리 백업의 복원 범위를 별도로 설계합니다.

## 현재 상태

후속 읽기 전용 `docker ps`에서 `property-manager-postgres`, 이미지 `postgres:16-alpine`, 호스트 포트 5432를 확인했습니다.
실제 서버 패치 버전·DB·권한·볼륨·백업 상태는 미확인입니다. DB·계정 생성, 권한 부여, 마이그레이션, 백업 변경은 수행하지 않았습니다.
프레임워크 버전·ORM·인증과 배포 운영 방식은 후속 상세 설계 사항입니다.
